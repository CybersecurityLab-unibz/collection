# Replication Package Collection

This repository collects replication packages for papers on green and sustainable software, AI-assisted development, software quality, vulnerability analysis, and architectural patterns.

Most top-level folders are Git submodules. For that reason, this README links submodule entries to their upstream GitHub repositories instead of linking to local relative paths, which may not resolve correctly in all Markdown renderers.
